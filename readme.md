# Will Rock — Viewer & Format Documentation

Инструменты для просмотра и разбора ресурсов игры **Will Rock** (Saber3D, 2003).

Will Rock — шутер от первого лица 2003 года на движке Saber3D. Игра использует собственный контейнерный формат для уровней, моделей и текстур. В репозитории — браузерные инструменты для просмотра этих ресурсов и документация по формату, восстановленная анализом данных и реконструкцией исходного кода беты.

---

## Содержимое

| Файл | Назначение |
|---|---|
| `willrock_viewer.html` | Просмотрщик уровней `.lg` и моделей `.tpl` (WebGL2, без установки) |
| `willrock_textures.html` | Просмотрщик и конвертер текстур `.pct` → PNG |
| `willrock_handoff.md` | Полная техническая документация по форматам и контекст проекта |

Оба инструмента — один HTML-файл, запускаются двойным щелчком в браузере. Ни установки, ни сервера, ни командной строки.

## Просмотрщик уровней и моделей

`willrock_viewer.html`

### Возможности

- Перетащите `.lg` (уровень) или `.tpl` (модель) в окно.
- Кнопка **«Папка игры…»** — выберите папку `TEXTURES` или всю папку игры, чтобы подключить текстуры и модели из `database/*.tpl`.
- Флажки: **текстуры**, **лайтмапы**, **полупрозрачность**, **сущности**, **зоны**.
- Сущности — расстановка объектов (предметы, враги, двери, триггеры) с координатами и свойствами.
- Зоны `&dom_*` — невидимые в игре триггеры, отображаются полупрозрачными объёмами.
- Вкладки **«Узлы / Сущности / Материалы»** с фильтром, сортировкой и цветовыми метками.
- Панель ресурсов: узел → материал → файл текстуры; сущность → шаблон → его текстуры.
- Экспорт в **OBJ** (с UV; ось X отзеркалена под правостороннюю систему).

### Управление (как в Blender)

| Действие | Клавиша |
|---|---|
| Выбрать объект | ЛКМ (Shift — добавить) |
| Вращать камеру | СКМ или Alt+ЛКМ |
| Сдвинуть камеру | Shift+СКМ |
| Масштаб | Колесо |
| Полёт | ПКМ + W A S D / Q E (Shift — быстрее, колесо — скорость) |
| Виды (спереди / сбоку / сверху) | Numpad 1 / 3 / 7 (или цифры) |
| К выбранному | `.` |
| Показать всё | Home |
| Скрыть выбранное | H (Alt+H — вернуть) |

### Ограничения

- Нужен браузер с WebGL2 (Chrome, Edge, Firefox).
- Скелетная анимация пока не проигрывается — модели отображаются в позе покоя.
- Запись `.lg` не реализована (только чтение и экспорт OBJ).

## Просмотрщик текстур

`willrock_textures.html`

- Перетащите файлы `.pct` или целую папку `TEXTURES`.
- Показывает формат, размер и превью каждой текстуры.
- Клик по миниатюре — сохранить PNG.
- Кнопка **«Только проблемные»** — показать нераспознанные форматы.

Поддерживаемые форматы: DXT1, DXT1+α, DXT3, DXT5, RGB24, ARGB32, RGB565 (big-endian), 2×8-bit (bump).

## Формат ресурсов — краткая справка

Полное описание — в `willrock_handoff.md`.

### Общий контейнер

    chunk = u16 tag, u32 end, payload     (little-endian)

`end` — абсолютное смещение конца блока от начала файла. Блоки вкладываются: дети ровно покрывают payload родителя. Пустой блок `0x0001` — маркер конца.

### Уровень `.lg`

Последовательность блоков верхнего уровня: узлы геометрии `0xf0`, сущности `0x1b8`, свет `0x280`, коллизия `0x21f`, встроенные шаблоны `0x1ea`, скрипты `0x21e`.

### Модель `.tpl`

Корень `0x2e4` → шапка `0x2e5` → текстуры → корневой узел `0xf0` → скины `0x2ee` → анимации `0x2e8` → последовательности `0x2e6` → свойства.

### Узел `0xf0`

Рекурсивная структура: имя (`0xf4`), матрица 4×4 (`0xf9`), вершины (`0xf1`), грани (`0x106` или `0xfe`), UV-каналы (`0x107` → `0xf3` → `0x103`), группы и материалы (`0x104`, `0x105`, `0x10a`), список материалов (`0x155`).

**Два варианта разметки:**

- Старый (`0x106`): уровни, простые модели, часть персонажей.
- Новый (`0xfe`): скелетные / морфинг-модели (например, `ai_mino_small`), материал задаётся у грани.

### Текстура `.pct`

Блоки `f0` (TCIP), `f1` (размер), `f2` (формат), `f9` (mips), затем `f4` (пиксели).

| Код | Формат |
|---|---|
| 0 | ARGB32 |
| 2 | RGB24 |
| 5 | RGB565 (big-endian) |
| 11 | 2×8 бит (bump, каналы неизвестны) |
| 12 | DXT1 |
| 13 | DXT1 + 1-бит α |
| 15 | DXT3 |
| 17 | DXT5 |

### Сущности (`0x1b8` → `0x1b9`)

    "SNIA" | имя\0 | шаблон\0 | класс\0 | пустая строка\0
          | матрица 4×4 (64 байта, позиция в последней строке)
          | блок 0x1ba (текст свойств, формат INI)

- **Шаблон** (`item_money`, `pwp_pistol`, `ai_cyclop`) → файл `database/<шаблон>.tpl`.
- **Класс** (`door`, `dynamic`, `water`, `sfx_waterfall`) → игровая логика.

## Статус и точность

- Контейнер, `.pct`, узлы геометрии, материалы, лайтмапы, сущности — **подтверждено** на данных пользователя.
- Скелеты, анимации, свет, коллизия, домены `&dom_*` — **частично** (структура блоков известна из реконструкции исходников беты, но не все параметры расшифрованы).
- Запись `.lg` — **не реализовано**.

Подробные метки достоверности — в `willrock_handoff.md`.

---

## Технические детали реализации

- **Парсер** — чистый JavaScript, `DataView` / `ArrayBuffer`, без зависимостей.
- **Декодер `.pct`** — DXT1/3/5 распаковываются вручную (без WebGL-сжатия), RGB24 / ARGB32 / RGB565 — прямым копированием.
- **Рендер** — WebGL2, один шейдер: диффузная текстура × лайтмап (×2), полупрозрачность через discard / альфу.
- **Raycast** — CPU-пересечение луча с треугольниками (AABB → треугольник) для выбора объектов.

## Источник знаний о формате

Формат восстановлен двумя путями:

1. **Анализ данных** — самосогласованность блоков (дети покрывают родителя, индексы в диапазоне, суммы групп = числу граней, UV в [0, 1], имена материалов → реальные файлы, позиции сущностей внутри геометрии).
2. **Реконструкция исходного кода беты от 21.02.2003** (`WillRock-Beta-Source-Reconstruction`) — декомпилят с настоящими именами функций из `.map`-файла. Используется как документация формата, не как код.

> ⚠️ Это декомпилят коммерческого кода. Инструменты в этом репозитории написаны с нуля на основе наблюдений за данными; исходники беты использовались только для уточнения структуры блоков. Не копируйте код из реконструкции в собственные проекты.

## Как пользоваться

1. Скачайте репозиторий (или отдельные `.html`).
2. Откройте `willrock_viewer.html` в браузере с WebGL2.
3. Перетащите `.lg` или `.tpl`, затем нажмите **«Папка игры…»** и выберите папку `TEXTURES` (или всю папку игры).
4. Играйте с камерой, выбирайте объекты, смотрите текстуры.

Аналогично для `willrock_textures.html` — перетащите `.pct` или папку `TEXTURES`.
